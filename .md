# Discord Auto Reply Bot

A C# Discord bot built with Discord.NET.

## Features

- Connects to a Discord server
- Receives messages
- Detects specific phrases
- Automatically responds to matching messages

## Current trigger

If someone writes:

> jag är sjuk

The bot responds:

> Yes, förstår ❤️ Hoppas det blir bättre!

## Technologies

- C#
- .NET
- Discord.NET
- Discord Gateway API

Create an environment variable containing your Discord bot token:

export DISCORD_TOKEN="YOUR_TOKEN_HERE"
